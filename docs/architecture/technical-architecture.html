1. 最终结论

采用：混合路线

继续在现有仓库开发，采用“自研核心 + 精准复用开源模块”。

真实 HTML/CSS/JavaScript 保持独立运行；HE Project Graph 保存稳定身份、Source Binding、时间线、交互和事务记录。

不采用：完整 Fork

不得 Fork OpenPencil、GrapesJS、Webstudio 或 Scena 作为产品底座，也不得用 Canvas SceneGraph 替代真实 DOM。

直接复用

Electron、Chromium、React、TypeScript、Vite、Zod、parse5、Magic String、PostCSS、CSSTree、Moveable、Selecto、Monaco、Vitest、Playwright、Electron Forge。

只借鉴、不绑定

OpenPencil 的包边界、格式 Adapter、CLI/MCP；Webstudio 的 CSS Inspector；Puck 的组件 Schema；Scena/Theatre 的时间线 UX；Remotion/HyperFrames 的后期视频输出工作流。

3. 数据权威关系

权威域负责内容禁止误解
用户 HTML / CSS / JavaScript网页语义、原始结构、未知代码、CSS 级联、独立运行结果不是唯一的工程数据来源
HE Project Graph 与附加数据稳定 ID、Source Binding、编辑器元数据、时间线、交互、revision、Operation Log不是完整 DOM 副本，也不替代网页源码
真实 DOM当前运行画面、命中测试、预览与最终浏览器行为不是独立持久化真相
Command / Transaction同步修改源码与 HE 数据，提供校验、回滚、Undo/RedoUI、Agent、插件不得绕过

4. 必须自研与复用边界

类别模块原则
必须自研HE Project Graph、Source Binding、Command/Transaction、视觉语义 Selection、Preview Bridge、Source Patch、CSS provenance、deterministic Timeline、Interaction Compiler这些能力决定产品是否成立和长期可控
直接复用浏览器、解析器、编辑控件、代码编辑器、测试与打包工具固定版本、记录许可证、通过 Adapter 隔离
后期 AdapterOpenPencil/.pen、Remotion、FFmpeg、HyperFrames、Lottie、Three.js/3DGS不得反向控制核心 Schema
opaque/embedCanvas/WebGL 内部、跨域 iframe、Closed Shadow Root、无源码动态节点、未知组件宁可明确降级，也不做虚假的“无损支持”承诺

5. MVP 成立条件

打开普通 HTML 项目 → 在真实画布中正确选择视觉对象 → 修改文字、属性、样式与基础变换 → 多选、拖动、缩放、吸附 → Undo / Redo → 最小化并安全回写源码 → 保存、关闭、重新打开 → 页面仍可独立运行 → HE Graph 与源码引用一致 → 外部修改冲突可见且不会误写

未通过该 Gate，不进入正式 Timeline、Agent/MCP、CRDT、最终 MP4 或 OpenPencil Adapter 开发。

6. 开发顺序

SCH-001 Schema 基础 → GRF-001 HE Project Graph → BND-001 Source Binding → CMD-001 Command Gateway → TXN-001 Transaction Core → PRV-001 Preview Bridge → SEL-001 接入现有 Selection Core → OVL-001 Overlay Editor → SRC-001 / CSS-001 → EDT-001 / STO-001 → 第一阶段人工闭环 Gate

PLT-001 的 Electron / React / Vite 应用壳可与 SCH-001 并行，但不得建立替代 HE Core 的临时业务模型。
