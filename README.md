# HTML Edit

**Agent 原生可视化多媒体 HTML 编排器**

HTML Edit 以真实的 HTML、CSS 和 JavaScript 页面作为可视化画布，并采用成熟非线性剪辑软件的时间线交互，统一编排 DOM 元素、媒体、动画和用户交互；设计师、开发者、自制 Agent 与通用 Agent 使用同一项目模型协同编辑。

## 当前确认的产品核心

1. 真实 HTML 可视化编辑
2. 剪辑软件式多轨时间线
3. 页面交互与状态编排
4. Agent 原生读写与协同

完整定义见：[docs/product-core.md](docs/product-core.md)
